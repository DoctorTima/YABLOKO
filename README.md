# YABLOKO

Интерактивы для «Московского Яблока».

## Что может муниципальный депутат?

Папка `deputat/` — готовая страница: `index.html`, шрифты Gilroy и логотип.

Адрес страницы: https://doctortima.github.io/YABLOKO/deputat/

### Как поставить на Tilda

1. Создайте в Tilda отдельную страницу.
2. Добавьте блок «Другое» → T123 «HTML-код», в настройках блока поставьте отступы сверху и снизу 0.
3. Вставьте код из файла `deputat/tilda-embed.html`.
4. Опубликуйте страницу и проверьте её на телефоне. В редакторе Tilda HTML-блок не показывается.

Интерактив встраивается рамкой на весь экран, поэтому стили Tilda его не ломают, а карточки мест на телефоне открываются снизу как обычно.
